===========================================================
 ExperienceHub - Credenciales iniciales
===========================================================

La base de datos se instala con estos usuarios ya creados.
Las claves se guardan HASHEADAS (PBKDF2-SHA256) en la base;
este archivo es la unica copia en texto plano.

Agrupados por ROL efectivo (el que determina las pantallas):

  ADMINISTRADOR  (acceso total)
    admin        / administrador1!

  AGENTE DE RESERVAS  (PN01 venta: Clientes, Contratacion-Venta;
                       PN02: Experiencias, Reservas, Reservas Realizadas, Lista de Espera)
    gcomercial   / usuario1!
    supervisor   / supervisor1!
    vendedor     / vendedor1!

  COORDINADOR DE EXPERIENCIAS  (catalogo: Experiencias, Categorias,
                                Ciudades, Organizadores, Planes)
    encargado    / usuario1!
    stock        / controladorstock1!
    operador     / operador1!
    ginventario  / usuario1!
    logistico    / usuario1!

  AUDITOR  (solo Bitacora + Reporte de Jornada)
    auditor      / usuario1!

  CAJA  (solo cobro de contrataciones, PN01)
    caja         / usuario1!

IMPORTANTE
- En el primer inicio de sesion puede pedirse cambiar la clave.
- Cambia la clave del usuario 'admin' despues de la primera entrada.
- Guarda este archivo en un lugar seguro o borralo tras configurar
  las cuentas definitivas.
